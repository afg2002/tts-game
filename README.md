# TTS Terminologi Kesehatan

Aplikasi Teka-Teki Silang (TTS) berbasis HTML, CSS, dan JavaScript untuk pembelajaran terminologi kesehatan.

## Fitur

- Crossword grid interaktif
- Soal mendatar dan menurun
- 11 materi terminologi kesehatan
- Input Nama, NIM, dan Kelas
- Validasi jawaban dan perhitungan nilai
- Reset puzzle
- Kunci jawaban
- Responsive untuk desktop dan mobile
- Tanpa backend dan dependency eksternal

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Development

Project ini dibuat sebagai aplikasi pembelajaran yang dapat dikembangkan lebih lanjut menjadi sistem penilaian dengan penyimpanan hasil mahasiswa dan dashboard laporan.
